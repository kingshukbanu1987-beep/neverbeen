# Live Chat face detection

These Tiny Face Detector weights are vendored from `@vladmandic/face-api` 1.7.15
(`model/tiny_face_detector_model*`, MIT license included). The lazy browser bundle
loads them from this same-origin directory; no external model host or image
upload is required. Only face bounding-box detection runs, not face recognition,
age/gender estimation or identity verification.

Source: https://github.com/vladmandic/face-api
